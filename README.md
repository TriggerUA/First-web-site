# First-web-site

A simple HTML and PHP project for learning.

## Running
1. Make sure PHP (version ≥ 8.1) is installed.
2. Start a local server in the project folder.
3. Open (http://localhost:8000) in your browser.
4. Fill out the form and submit the data.
